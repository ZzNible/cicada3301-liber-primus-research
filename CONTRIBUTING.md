# Contributing

Contributions are welcome, especially when they improve provenance or prevent duplicated work.

## Good contributions

Please open an issue or pull request when you have:

- a historical artifact with provenance;
- an independently preserved copy of a known object;
- an old solver archive with original acquisition context;
- a correction to transcription, page mapping, punctuation, layout or source attribution;
- a falsifiable mechanism with parameters fixed before LP2 inspection;
- a reproduction or falsification of a published result;
- a negative result with controls and clearly stated scope.

## Evidence labels

Use these terms carefully:

- `ESTABLISHED`
- `SIGNAL`
- `HYPOTHESIS`
- `OPEN`
- `REJECTED`
- `COINCIDENCE`

Do not describe a plausible interpretation as established evidence.

## Historical artifacts

If you possess old files:

1. keep the original untouched;
2. compute a cryptographic hash if possible;
3. record where and when you obtained it;
4. distinguish original bytes from later exports/screenshots/transcriptions;
5. do not strip metadata before preserving a copy.

If redistribution rights are unclear, provide hashes, metadata and provenance first rather than posting the object publicly.

## Cryptanalytic claims

For a proposed decode, include enough information to replay the complete search:

- exact input corpus;
- transformation;
- parameters;
- how parameters were selected;
- number of alternatives searched;
- full output, not only attractive fragments;
- null/control comparison where relevant.

English-looking snippets produced after a large flexible search are not sufficient evidence.

## New mechanisms

The current LP2 transition line is on hold unless a new mechanism is independently motivated.

A useful proposal should explain what new observable it predicts **before** looking at the relevant LP2 result.

## AN END

For historical deep-web objects, exact bytes and custody matter more than trying additional hash algorithms. Preserve the representation first; digest comparisons come second.
